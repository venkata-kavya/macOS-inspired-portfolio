# KARTA

KARTA is a gamified neural thought-mapping mobile concept designed around the idea that thoughts should be explored as connected systems rather than isolated notes.

The build combines a mobile-first interface with AI-assisted organization, embeddings and vector search. The goal is a product that makes reflection, recall and idea discovery feel visual and playful.

**Stack:** React Native · Expo · Supabase · Pinecone · OpenAI/LLM APIs · Tailwind-style UI
