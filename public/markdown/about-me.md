# About Kavya

## Introduction

Hi, I'm **Venkata Kavya** — an AI/ML engineer and builder interested in the space where **technology, neuroscience, and human behavior** meet.

I build intelligent applications with a particular question in mind:

> **What if technology worked with the human mind instead of constantly competing for it?**

I'm interested in how attention, memory, reward, curiosity, habits, and information environments shape the way we think. That curiosity influences the products I build — from AI systems and cognitive tools to interfaces designed to make technology feel more intentional.

Technically, I work across Python, Java, SQL, LLM applications, RAG, embeddings, agent orchestration, FastAPI, React, TypeScript and vector search. I completed my AIML internship at Cognizant in 2026, where I worked on practical AI/ML systems.

But technology is only half of what interests me.

I'm fascinated by **neuroscience, cognition, learning, behavioral psychology, and the unintended consequences of the systems we build.** I want to explore how software can help people think better, learn more deeply, and retain control over their attention.

## What I Care About

### 🧠 Neuroscience × Technology

I'm deeply interested in the mechanisms behind attention, memory, motivation, reward, learning and habit formation.

The brain is an incredibly complex system, and I don't think software should pretend otherwise.

I want to build applications that are informed by how humans actually think and learn — rather than simply optimizing for clicks, session time, notifications and engagement.

### ◌ Fighting for Attention Back

Modern software is exceptionally good at capturing attention.

Infinite feeds. Notifications. Variable rewards. Recommendation loops. Short-form content. Personalized outrage.

A lot of technology is built around one metric:

**How long can we keep you here?**

I'm interested in the opposite question:

> **How can we build technology that gives your attention back?**

That means designing products that don't need to manufacture compulsive engagement to be useful.

Software should be allowed to say:

**"You're done. Go live your life."**

### 🪞 Escaping Echo Chambers

Personalization is powerful — but personalization can also become a cognitive trap.

When algorithms continuously show us more of what we already believe, our information environment becomes narrower while feeling increasingly certain.

I'm interested in applications that deliberately introduce:

- opposing perspectives
- unfamiliar ideas
- diverse sources
- intellectual friction
- uncertainty
- context

Not to create noise, but to make it harder for an algorithm to quietly decide what we should think.

### 🧩 Building Future-Safe Applications

I don't want to build applications that are impressive for six months and irrelevant afterward.

I'm interested in **future-safe software** — applications that remain useful as models, platforms and technologies change.

That means focusing on:

- human agency
- durable knowledge
- privacy
- interoperability
- transparent AI
- user-controlled data
- explainable systems
- meaningful interaction rather than engagement hacking

AI should be a tool people can reason with, question and control — not an invisible system quietly making decisions for them.

## What I'm Building Toward

I'm exploring the idea of **cognitive technology**: software that helps people understand themselves, learn, think, create and navigate information without surrendering their agency.

Some of the questions I'm interested in:

- Can software help us **remember instead of endlessly consume**?
- Can AI expose us to perspectives we would never encounter on our own?
- Can interfaces be designed around **attention preservation rather than attention extraction**?
- Can personal AI help us think without becoming another filter bubble?
- Can technology make deep work easier instead of making distraction easier?
- Can we build systems that understand human behavior without exploiting it?

I don't have all the answers.

That's part of the reason I'm building.
