# Kavya — macOS Portfolio

An interactive portfolio for **Venkata Kavya**, built as a playful macOS-inspired desktop experience.

## What is inside

- AI/ML + agentic AI focused profile
- KARTA, AI Resume Analyzer and Atelier Céleste projects
- Interactive Finder, Terminal, Safari, Notes, VS Code, Launchpad and more
- Dark/light mode, widgets, window management and keyboard shortcuts
- Inter as the only UI typeface

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
